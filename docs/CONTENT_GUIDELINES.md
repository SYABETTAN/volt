# Ligne éditoriale

Français soigné, concret, sans promesse de délai, de prix de travaux, de note ou d’agrément. Le vouvoiement est de rigueur. Pas de latin de remplissage.

## Ce qui doit rester visible en démonstration

- `Site de démonstration — entreprise fictive.` dès le premier écran et dans le pied de page
- `Projet illustratif` sur chaque réalisation
- `Avis fictifs — exemples de présentation`
- `Chiffres fictifs — exemples de mise en page`
- `Certifications réelles à renseigner`
- `Démonstration — aucune demande n’est envoyée.` sur le devis

## Ce qui est interdit

- Présenter une photographie de banque d’images comme un chantier VOLT
- Inventer un SIRET, une adresse, un téléphone ou une assurance
- Afficher un logo Qualifelec, RGE ou équivalent sans document
- Écrire « avis Google », une note sur 5 ou un schéma `Review`
- Annoncer un message envoyé quand la messagerie de la personne s’ouvre seulement

## Ton

Phrases courtes. Le métier est nommé : tableau, circuit, pièce, devis. Les superlatifs et le vocabulaire de luxe vestimentaire sont hors sujet.

## Mode client

Retirer les pastilles seulement après avoir remplacé les textes. Une phrase encore fictive dans un avis marqué `verified: true` est une faute de contenu, pas un réglage technique : le validateur ne lit pas la sincérité d’une citation.
